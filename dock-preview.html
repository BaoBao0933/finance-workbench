1四个需求逐个看

需求实现
底部居中浮动玻璃fixed + 左50% + translateX(-50%)，毛玻璃 + 内描边高光
只放图标原「图标+文字」横排项，dock 里只留图标
当前放大 + 相邻跟随JS 算鼠标到每个图标的水平距离，按平方衰减写 CSS 变量
上方显示名称悬停时 ::after 气泡浮出（content: attr(data-tip)）
当前页小圆点.active 项下方 5px 金点 + 首次弹跳

2「相邻跟随」为什么必须用 JS

纯 CSS 的 :hover + .next 只能让直接相邻的那一个放大， 而 macOS Dock 是「距离鼠标越近放大越多」的连续曲线。 所以必须由 JS 在移动时逐个算距离、写 CSS 变量。

距鼠标放大说明
0px1.42×悬停项本身
12px1.34×左右邻居（明显）
24px1.27×隔一个（仍看得出）
46px1.14×第四个（轻微）
92px+1.00×不放大
⭐ 用平方而不是线性衰减：线性看起来像一排被推开的积木， 平方才有「中间鼓起来」的弧度 —— 这是 macOS Dock 的辨识度所在。

3一个修掉的 bug

第一版算法在 d≈6px 处会翘到 1.59×，比悬停项本身（1.42×）还高 —— 鼠标明明在 A 上，旁边 B 却鼓得更高，视觉像在抖。
测试里加了一条硬断言「d=0 必须是全局最大值」当场抓住， 改成 (1 + near × (1-t)) 后曲线恢复正常。
