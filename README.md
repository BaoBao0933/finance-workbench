# 包包财经工作台 · BaoBao Finance Workbench

> 一个不刷新的 A 股盘中工作台：行情、资金、板块、龙虎榜、财联社电报，一屏看完。
> 单文件前端 · 零框架 · 玻璃拟态 + 2.5D 图标 · 支持深色/浅色与手机端。

**在线体验**：https://baobao0933.github.io/finance-workbench/
**桌面版**：Electron 打包，`finance-desktop/` 目录（Windows）

---

## 为什么做这个

盯盘软件要么太重（装客户端、注册账号、满屏广告），要么太散（开五六个网页来回切）。
我做的是一个**自己的盘面**：打开就能看到今天该看的东西，不用登录、不用刷新、不弹窗。

设计上刻意做了三件事：

1. **信息密度优先**——首屏就是大盘、持仓、板块涨跌、资金流向，不做多余的引导页。
2. **东方习惯**——涨红跌绿、`+1.2 亿`、`放量 1.2 倍`，不用二次换算。
3. **有呼吸感**——玻璃拟态 + 入场动画 + 2.5D 图标，但动画只做"流动"，绝不遮挡读数。

## 功能一览

| 模块 | 内容 |
|---|---|
| 首页 | 核心指数（上证/科创50/创业板）、全球市场、热门板块条、今日要闻 |
| 行业板块 | 124 个行业 + 803 个概念的涨跌、资金净流入、领涨股 |
| 资金流向 | 主力净流入排行、板块资金、北向（南向）资金 |
| 走势分析 | 指数分时 + 技术指标 + 市场情绪 |
| 期货市场 | 国内主要商品期货与股指期货 |
| 重点关注 | 自选关注池，命中即高亮 |
| 财经要闻 | **财联社电报**（A/B 级重点标红）+ 东财快讯，支持自定义关注板块/关键词 |
| 龙虎榜 | 每日上榜个股、席位、净买卖 |
| 自选股票 / 持仓股 | 本地保存，算出浮动盈亏与仓位 |
| 全局 | 深色/浅色切换、头像与板块自定义、数据源自动降级 |

### 几个细节

- **不刷新**：所有数据都是局部更新，切页不重载。
- **数据源自动降级**：主源连不通时自动切备用通道，并在顶部状态条说明当前用的是哪条。
- **离线不白屏**：断网时保留布局，逐块显示「行情通道恢复中…」，恢复后自动补齐。
- **财联社电报**：官方接口有签名且限制跨域，因此由 GitHub Actions 每 10 分钟抓取为同源 JSON（`cls-news.json`），
  前端只读文件。超过 8 小时未更新会自动隐藏整块，避免把隔夜旧闻当最新。
- **本地优先**：自选、持仓、板块配置、关注词全部只存在浏览器 `localStorage`，不上传任何服务器。

## 技术说明

- **单文件**：`index.html` 一个文件包含全部 HTML/CSS/JS（约 2 MB），无构建、无框架、无外部字体。
- **分层注入**：视觉与交互按模块拆分（`glass-pro/`、`motion-cine/`、`home-iso/`、`cls-feed/` …），
  每个模块有自己的 `inject.py`（幂等注入）与 `test-inject.py`（结构/可逆/幂等断言，合计 900+ 项）。
- **2.5D 图标**：由等距几何工具计算（`extrude` / `lathe` / 圆柱），四档侧面色调由算法给出，
  不是手绘 SVG。改图标改脚本重跑，见 `home-iso/build-icons.mjs`。
- **动效**：CSS `linear()` 采样二阶欠阻尼曲线；图标点击走"一次冲量 + 弹簧回落"（k=150 d=8.5）。
- **性能**：首屏 FCP ≈ 270 ms；滚动期自动降级高成本滤镜；离屏动画自动暂停。

## 本地运行

```bash
# 方式一：直接打开（部分功能需要 http 环境，建议用方式二）
start index.html

# 方式二：起一个静态服务
python -m http.server 8080
# 然后访问 http://127.0.0.1:8080/index.html
```

桌面版：

```bash
cd finance-desktop
npm install
npx electron .
```

## 数据来源

| 用途 | 来源 |
|---|---|
| 指数/个股/板块行情 | 腾讯财经、新浪财经 |
| 板块资金、龙虎榜 | 东方财富 |
| 财经快讯 | 东方财富、**财联社电报**（经 GitHub Actions 定时抓取） |
| 全球市场 | 新浪财经 |

所有数据仅用于个人学习与研究展示，不构成任何投资建议。

## 已知限制

- 依赖第三方公开接口，接口变更或限流时部分模块会降级（页面会提示）。
- 财联社电报的更新依赖 GitHub Actions 定时任务，最长可能有约 10 分钟延迟。
- 桌面版为 Windows x64；其它平台需自行打包。
